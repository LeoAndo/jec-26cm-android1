9　変数で文を作ろう

名前と学年を変数に入れて、1つの文を作ります。

この回の言葉

変数は値に付ける名前です。Stringは文字列、intは整数です。=は右の値を左の変数へ入れます。文の最後は半角の;です。+で文字列と数をつなぎます。この時点では文を作るだけです。

9-1　MainActivity.javaを変更する

開くファイル：app/src/main/java/jp/ac/jec/a02profilecard/MainActivity.java

  1. Android Studioのファイル一覧で、このファイルを開きます。
  2. ⌘Fで// ここから授業の処理を追加します。を探します。
  3. その場所を含む「変更前」と同じ範囲だけを選び、置き換えます。

変更前（直前の手順が終わった状態）

// ここから授業の処理を追加します。

変更後（この範囲だけを貼り付ける）

// ここから授業の処理を追加します。

String message = "こんにちは！" + grade + "年生の" + name + "です。";

package jp.ac.jec.a02profilecard;

import android.os.Bundle;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(
                    WindowInsetsCompat.Type.systemBars() | WindowInsetsCompat.Type.ime());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });

        // ここから授業の処理を追加します。
        String name = "サクラ";
        int grade = 1;
        String message = "こんにちは！" + grade + "年生の" + name + "です。";
    }
}

11　ボタンであいさつしよう
