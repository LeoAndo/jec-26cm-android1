はじめる前に

使う環境はmacOS、Android Studio Panda 2 | 2025.3.2、教員が指定したスマートフォン型のエミュレーターです。A01で練習したRunと、ファイルの編集を使います。

今回は新しくプロジェクトを作りません。開始用ファイルを開きます。第3・4週も同じプロジェクトを続けます。

まず動かしてみよう

  1. 開始用プロジェクト（ZIP）をダウンロードします。
  2. FinderでZIPをダブルクリックします。
  3. 展開されたA02ProfileCardフォルダーを、授業用の作業場所へ移します。
  4. Android Studioの最初の画面でOpenを選びます。別のプロジェクトが開いている場合はFile → Openを使います。
  5. A02ProfileCardフォルダーを選びます。appだけを選ばないでください。
  6. Gradleの同期が終わるまで待ちます。
  7. 上部の実行先で、教員指定のエミュレーターを選びます。
  8. Run → Run 'app' を選びます。

「自己紹介カード」の見出しだけが出ればOKです。

開けない・一覧が見えないとき

settings.gradle.ktsとgradlewが入ったフォルダーを選びます。ファイル一覧が見えないときはView → Tool Windows → Projectで戻します。同期が失敗したら、Gradleの最初のエラーを教員に見せます。

開くファイルと残す部分

activity_main.xmlはapp → res → layout、strings.xmlとcolors.xmlはapp → res → valuesにあります。XMLはCodeで文字を編集します。Javaはappのjava内のjp.ac.jec.a02profilecard → MainActivityを開きます。同名のtestフォルダーは使いません。

mainとcontentの枠、ScrollView、画面端の余白処理は教員が準備済みです。入力欄と下のボタンの間は、標準のエラー案内が重ならないよう48dp空けます。ScrollViewは画面に入りきらない部分を上下へ動かす枠です。学生はその内側に部品を追加します。この課題で指定するファイルだけを編集します。

編集内容はAndroid Studioが自動保存します。コードのコピーは⌘C、貼り付けは⌘Vです。コード欄に行番号や差分記号はありません。

5　名前とあいさつを置こう

文字を表示する部品を2つ追加します。

この回の言葉

TextViewは文字の部品です。layout_widthは横、layout_heightは縦の大きさです。match_parentは親の幅、wrap_contentは中身に必要な大きさです。dpは余白や部品の大きさ、spは文字の大きさに使います。

5-1　strings.xmlを変更する

開くファイル：app/src/main/res/values/strings.xml

  1. Android Studioのファイル一覧で、このファイルを開きます。
  2. ⌘Fで</resources>を探します。
  3. その場所を含む「変更前」と同じ範囲だけを選び、置き換えます。

変更前（直前の手順が終わった状態）

</resources>

変更後（この範囲だけを貼り付ける）

    <string name="default_name">サクラ</string>
    <string name="default_greeting">よろしくお願いします。</string>
</resources>

この範囲以外は残します。ファイル全体の置き換えではありません。

5-2　activity_main.xmlを変更する

開くファイル：app/src/main/res/layout/activity_main.xml

  1. Android Studioのファイル一覧で、このファイルを開きます。
  2. ⌘Fで<!-- カードの部品はここに追加します。 -->を探します。
  3. その場所を含む「変更前」と同じ範囲だけを選び、置き換えます。

6　横向きの枠を作ろう

名前を横向きのLinearLayoutの中へ移します。

この回の言葉

orientation="vertical"は縦、horizontalは横です。枠の中に枠を置くことを入れ子と呼びます。paddingは枠の内側、layout_marginBottomは枠の外側の下の余白です。gravityは枠の中で部品をそろえる位置です。

6-1　activity_main.xmlを変更する

開くファイル：app/src/main/res/layout/activity_main.xml

  1. Android Studioのファイル一覧で、このファイルを開きます。
  2. ⌘Fでandroid:id="@+id/nameTextView"を探します。
  3. その場所を含む「変更前」と同じ範囲だけを選び、置き換えます。

変更前（直前の手順が終わった状態）

<TextView
    android:id="@+id/nameTextView"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:layout_marginBottom="24dp"
    android:text="@string/default_name"
    android:textColor="@color/card_text"
    android:textSize="24sp"
    android:textStyle="bold" />

変更後（この範囲だけを貼り付ける）

<LinearLayout
    android:id="@+id/profileRow"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:layout_marginBottom="24dp"
    android:gravity="center_vertical"
    android:orientation="horizontal">

    <TextView
        android:id="@+id/nameTextView"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="@string/default_name"
        android:textColor="@color/card_text"
        android:textSize="24sp"
        android:textStyle="bold" />

</LinearLayout>

この範囲以外は残します。ファイル全体の置き換えではありません。

こうなればOK

  1. Run → Run 'app' を選びます。
  2. ビルドと起動が終わるまで待ちます。
  3. 見た目は大きく変わりません。名前を囲むprofileRowのorientationがhorizontalです。
うまくいかないとき

タグの数が合わないときは、profileRowの開始と終了のLinearLayoutを指で対応させます。外側のcontentとmainは残します。

直せないときは、開いているファイルとBuildの最初のエラーを教員に見せます。
