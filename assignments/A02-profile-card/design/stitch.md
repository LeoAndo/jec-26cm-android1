## 接続と取得方法

- プロジェクト：[26CM_Android1](https://stitch.withgoogle.com/projects/3692358824817406400)、ID `3692358824817406400`。
- この実行環境にStitch MCPのツールは公開されていなかった。**MCP接続・自動同期を構築したとは扱わない。**
- ユーザーの追加依頼により、教員側の生成依頼と修正依頼をブラウザー操作で送信した。最初の閲覧専用アカウントから、ユーザーのログイン操作で編集できるアカウントへ切り替えた。
- 生成後に「もっと画面要素を減らしてください」を反映し、好きなことの行、重複見出し、余計な解説・装飾を削除した。
- 取得日時：2026年9月14日21:36 JST。1画面ずつ選択名を確認し、Export → コードをクリップボードにコピーで取得した。ブラウザーで取得した文字列をローカル保存した。
- 6件のHTML原本、画面ID、SHA-256：[manifest.json](stitch-export/manifest.json)。更新された同じ画面IDとの版の違いはハッシュで区別する。
- 画面全体のPNG・ZIPエクスポートは取得できていない。ZIPのダウンロード待機は2回ともタイムアウトした。画像の取得済み範囲はHTML内のURLから取得した[プロフィール素材](stitch-export/profile-avatar.png)のみ。
- ブラウザー上の変更はAndroidへ自動同期されない。原本を取得し、教員側で差分を判断してJava／XMLへ反映し、動作と教材を検証する流れ。

## Java・XMLへ反映した内容

| 項目 | 採用・調整 |
| --- | --- |
| 構成 | 見出し1つ、画像と名前の横並び、あいさつ、あいさつボタン。第4週に名前ラベル・入力欄・反映・リセットを加える。 |
| 色と大きさ | S04を主に参照。背景#FEF7FF、本文#1D1B20。ボタンの色はAndroidのテンプレートテーマを使う。内側24dp、画像48dp、画像と名前の間12dp。名前24sp、本文18spへ授業用に調整。 |
| 入力欄・ボタン | 標準EditText・Buttonを使用。リセットは枠線のMaterialボタン。タップ領域は48dp以上。Webの40pxをそのまま使わない。 |
| エラー案内 | HTMLの赤枠・独自エラーを移植せず、仕様どおりEditText.setErrorを使う。Android 17で吹き出しと下のボタンが重なったため、入力欄とボタン行の間を48dpにした。 |
| 長い名前 | 名前の幅にlayout_weightを使い、wrap_contentの高さで全文を折り返す。画面はScrollView。 |
| キーボード | mainのsystemBarsとimeのInsetsを合成し、adjustResizeと組み合わせる。 |
| 生成コードの挙動差 | 一部にmaxlength=20、入力欄をサクラへ戻すreset、学年のないあいさつ、隠れたtoastがあった。これらは採用しない。空白の判定・反映済みの名前・リセットの初期値は課題READMEを正本とする。 |
| 学習順 | Stitchには最終状態のリセットがあるが、学生の第15回までの必須コードには入れない。第16回に仕様から自力追加する。 |

ユーザーの追加方針により、Androidのテーマは生成されたDayNight設定を維持する。Lightへの変更・forceDarkAllowedの追加・テーマ色の上書きは行わない。Stitchのライト状態は配置の参考であり、学生にテーマ切り替えやダーク状態の検証を要求しない。

Web用JavaScript・CDN・フォントはAndroidへ同梱しない。取得原本は変更せず保存する。Androidの実行画像はmaterials/assetsに保存し、Stitchの画面PNGと混同しない。
