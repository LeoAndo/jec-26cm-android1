はじめる前に確かめよう

アプリを作る道具と、練習用のスマートフォンを確かめます。

操作する場所　Android Studio（アンドロイド スタジオ）

パソコンの中で動く練習用のスマートフォンを「エミュレーター」と呼びます。授業では、教員が指定したものを使います。

やってみよう

  1. Android Studioを開きます。
  2. Android Studio → About Android Studio を開きます。
  3. バージョンが Panda 2 | 2025.3.2 か確かめます。
  4. バージョンの画面を閉じます。
  5. 教員と一緒に、使うエミュレーターの名前を確かめます。
エミュレーターの作成と必要なファイルのダウンロードは、授業前に教員と済ませておきます。名前がわからない場合は、先に教員へ伝えてください。
こうなればOK指定されたAndroid Studioを開き、使うエミュレーターの名前がわかります。
うまくいかないとき

バージョンが違う場合は、画面を教員に見せてください。インストールが進まない場合は、表示されている文章を消さずに見せてください。

アプリを作る準備をしよう

アプリを作るためのファイル一式を用意します。このまとまりを「プロジェクト」と呼びます。

操作する場所　Android Studio → New Project

やってみよう

  1. 最初の画面で New Project（新しいプロジェクト）を押します。すでにプロジェクトを開いている場合は File → New → New Project を選びます。
  2. Phone and Tablet の中から Empty Views Activity を選びます。
  3. Next（次へ）を押します。
  4. 下の表のとおりに入力・選択します。
欄の名前 入力・選択する内容
Name（プロジェクト名） A01FirstApp
Package name（アプリを区別する名前） jp.ac.jec.a01firstapp
Save location（保存する場所） 自分が見つけられる場所。最後のフォルダー名は A01FirstApp。
Language（使う言語） Java
Minimum SDK（対応するAndroidの下限） API 30
その他の欄 最初の設定を使います。
  1. Save locationに表示された場所を、ノートに書きます。
  2. Finish（完了）を押します。
  3. 画面下の準備中の表示が終わるまで待ちます。
Empty Views Activity と Empty Activity は別のものです。今回は「Views」が入った名前を選びます。Javaが選べないときは、前の画面へ戻って名前を確かめます。
こうなればOKA01FirstAppが開き、ファイル一覧が表示されます。準備中の表示が終わっています。
うまくいかないとき

ダウンロード中は時間がかかることがあります。失敗した文章が出た場合は、文章とインターネットの接続状態を教員に見せてください。新しいプロジェクトを何個も作る必要はありません。

まずアプリを動かしてみよう

最初に用意されたアプリを動かします。まだ完成図と違っていても大丈夫です。

操作する場所　Android Studioの上部と、練習用のスマートフォン

コードから動かせるアプリを作ることを「ビルド」と呼びます。「実行」を選ぶと、ビルドしたアプリが練習用のスマートフォンで開きます。

やってみよう

  1. 上部の実行するものの欄で app を選びます。
  2. 実行先の欄で、教員と確かめたエミュレーターを選びます。
  3. メニューの Run → Run 'app' を選びます。上部の三角形のRunボタンでも実行できます。
  4. ビルドと、スマートフォンの起動が終わるまで待ちます。
  5. スマートフォンの中に、アプリの画面が出たことを確かめます。

この時点の文字や色は、最初のひな形によって決まります。次の授業で、みんな同じ画面に変えます。

こうなればOK自分が作ったプロジェクトから、アプリを起動できました。
うまくいかないとき

実行先がない場合は、教員に「エミュレーターが選べません」と伝えてください。赤いエラーが出た場合は、画面下の Build にある最初のエラーを見せてください。

使うファイルを開いてみよう

これから使うファイルを開きます。ファイルごとに、役割が違います。

操作する場所　Android StudioのProject（ファイル一覧）

やってみよう

  1. 左側の Project で、A01FirstApp の横の矢印を押して開きます。
  2. フォルダーの横の矢印を押して、app → src → main の順に開きます。
  3. 下の表にあるファイルを、1つずつダブルクリックします。
mainからたどる場所 何が書いてあるか
java/jp/ac/jec/a01firstapp/MainActivity.java 最初の画面を表示する処理。名前がドットでまとめて表示される場合もあります。
res/layout/activity_main.xml 画面に置く部品と、その並べ方。
res/values/strings.xml 画面に出す言葉や、アプリの名前。
AndroidManifest.xml 使う画面など、アプリの登録。

ファイルの上にあるタブを押すと、開いたファイルを切り替えられます。XMLを開いて絵が表示された場合は、編集欄の Code または Split を選ぶと文字が見えます。

こうなればOKMainActivity.java、activity_main.xml、strings.xmlを開けます。
うまくいかないとき

Projectの一覧が見えない場合は、左端のフォルダーの形のボタンを押します。表示方法がProject以外の場合は、一覧上部で Project を選びます。

同じ名前がある場合は、app/src/main からの場所を比べてください。ファイルが見つからない場合は、ファイル一覧を教員に見せてください。別の場所に同じファイルを作らずに確認しましょう。

画面に文字を置こう

Empty Views Activityが作ったコードを、少しずつ変えます。変更前と変更後を比べましょう。

操作する場所　手順05で開いたファイル

今回、変えるファイル

ファイル変えること
strings.xmlアプリの名前を変え、あいさつを1行追加する。
activity_main.xml部品の入れ物をLinearLayoutに変え、文字と余白を整える。
MainActivity.java、AndroidManifest.xml、Gradleの設定変更しない。

入力する記号は変更後の例と同じにします。コピーは ⌘ + C、貼り付けは ⌘ + V です。変更する文字だけを選んで貼り付けます。

変更前のコードが見つからない場合は、開いているファイルを教員に見せてください。MainActivity.javaはJavaで作ったものを使います。

① 表示する言葉を用意する

app/src/main/res/values/strings.xml を開きます。

  1. app_name の言葉を A01FirstApp から はじめてのアプリ に変えます。
  2. その下に、greeting_message の行を追加します。</resources> の前に入れます。

変更前

<resources>
    <string name="app_name">A01FirstApp</string>
</resources>

変更後

<resources>
    <string name="app_name">はじめてのアプリ</string>
    <string name="greeting_message">Hello, Android!</string>
</resources>

② 部品の入れ物を変える

app/src/main/res/layout/activity_main.xml を開きます。文字を表示する部品が TextView、部品を並べる入れ物が LinearLayout です。

  1. 先頭と末尾の androidx.constraintlayout.widget.ConstraintLayout を LinearLayout に変えます。
  2. xmlns:app の行を消します。
  3. 外側の入れ物に android:orientation="vertical" と android:background="#FFFFFF" を追加します。
  4. TextViewの外側に、変更後の例のようにもう1つLinearLayoutを追加します。
  5. TextViewの app:layout_constraint で始まる4行を消します。
  6. TextViewの横幅と表示する言葉を、変更後の例に合わせて変えます。
  7. TextViewに android:id、android:textSize、android:textColor、android:gravity を追加します。

android:id="@+id/main" は残します。Javaのコードが、この名前を使って画面の上下の余白を整えます。内側のLinearLayoutは、文字の周りに24dpの余白を作ります。

変更前

<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/main"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    tools:context=".MainActivity">

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello World!"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintTop_toTopOf="parent" />

</androidx.constraintlayout.widget.ConstraintLayout>

変更後

<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:tools="http://schemas.android.com/tools"
    android:id="@+id/main"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:background="#FFFFFF"
    tools:context=".MainActivity">

    <LinearLayout
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        android:orientation="vertical"
        android:gravity="center"
        android:padding="24dp">

        <TextView
            android:id="@+id/greetingText"
            android:layout_width="match_parent"
            android:layout_height="wrap_content"
            android:text="@string/greeting_message"
            android:textSize="24sp"
            android:textColor="#212121"
            android:gravity="center" />

    </LinearLayout>
</LinearLayout>

外側のLinearLayout、内側のLinearLayout、TextViewの順に入っています。閉じる </LinearLayout> が2つあることも確かめます。

変更後のファイル全体を確かめる

③ Javaのコードを確かめる

MainActivity.java を開きます。このファイルは変更しません。

  1. setContentView(R.layout.activity_main); を探します。②の画面を表示する指示です。
  2. findViewById(R.id.main) を探します。②で残した main とつながっています。
MainActivity.javaの初期コードを確かめる（変更しない） 
package jp.ac.jec.a01firstapp;

import android.os.Bundle;

import androidx.activity.EdgeToEdge;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main), (v, insets) -> {
            Insets systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars());
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom);
            return insets;
        });
    }
}

最初からある画面端の余白を整える処理は、そのまま使います。詳しい仕組みは、今は覚えなくて大丈夫です。

こうなればOK文字列と画面XMLを変更しました。MainActivity.javaは最初のままです。次の手順で動かします。
うまくいかないとき

間違えたら Edit → Undo（元に戻す）で戻せます。赤い線が残る場合は、変更前後の例と記号を比べます。R.id.main に赤い線が出た場合は、画面XMLに android:id="@+id/main" があるか確かめます。

表示する言葉を探そう

画面と、表示する言葉が、どこでつながっているか見つけます。

操作する場所　activity_main.xml と strings.xml

やってみよう

  1. 手順05の場所から activity_main.xml を開きます。
  2. android:text="@string/greeting_message" を探します。
  3. strings.xml を開きます。
  4. name="greeting_message" を探します。
  5. その右にある Hello, Android! を指で示します。

greeting_message は、表示する言葉につけた名前です。画面は、この名前を使って、表示する言葉を取り出します。

画面の指定：@string/greeting_message
                    ↓
言葉の名前：greeting_message
表示する言葉：Hello, Android!

上はつながりを表す説明図です。コードとして貼り付けません。

こうなればOK表示する言葉が書かれている場所を指で示せます。
うまくいかないとき

見つからない場合は、手順06の①と②を見ます。画面に出る言葉と、言葉につけた名前は別です。この手順では、まだ何も変えません。

日本語のあいさつに変えよう

画面に出る言葉を、日本語に変えます。

操作する場所　app/src/main/res/values/strings.xml

やってみよう

  1. 手順05の場所から strings.xml を開きます。
  2. Hello, Android! を探します。
  3. その言葉だけを こんにちは、Android！ に書き換えます。
  4. Run → Run 'app' を選びます。
  5. アプリが表示されるまで待ちます。
  6. 画面の言葉を読みます。

ここを書き換えます

変更前の1行：

<string name="greeting_message">Hello, Android!</string>

変更後の1行：

<string name="greeting_message">こんにちは、Android！</string>

<string name="greeting_message"> と </string> の記号は残します。greeting_message という名前も残します。

変更後のファイル全体

<resources>
    <string name="app_name">はじめてのアプリ</string>
    <string name="greeting_message">こんにちは、Android！</string>
</resources>
変更前（説明図）Hello, Android!
変更後（説明図）こんにちは、Android！

日本語の最後は全角の「！」です。Androidの前には日本語の「、」を入れます。

こうなればOK白い画面に「こんにちは、Android！」と表示されます。
うまくいかないとき

まだ英語が出る場合は、文字を変更した後にもう一度Runを選び、完了まで待ちます。赤い線が出た場合は、上の「ファイル全体」と前後の記号を比べます。直せない場合は、開いているファイルを教員に見せてください。
