自分で少し変えてみよう

学んだ操作を使って、自分であいさつを変えます。

操作する場所　strings.xml と、練習用のスマートフォン

やってみよう｜全員が行う練習

  1. 「こんにちは」を「おはよう」に変えたら、画面に何が出るか予想します。
  2. strings.xml の greeting_message の言葉を おはよう、Android！ に変えます。
  3. Run → Run 'app' を選びます。
  4. 実行が終わった画面を、予想と比べます。
  5. 変えた行とアプリの画面を教員に見せます。
  6. 言葉を こんにちは、Android！ に戻します。
  7. Run → Run 'app' を選びます。
  8. 必須課題のあいさつに戻ったことを確かめます。

前の手順を見ながらでもよいです。文字を変える方法を見る →

追加の練習｜終わった人だけ

自分で考えた短いあいさつに変えて、動かしてみましょう。文字は日本語・英字・数字を使います。今回は <、&、引用符などの記号は使いません。終わったら、必須のあいさつに戻して、実行します。

こうなればOK「おはよう、Android！」への変更を実演できました。最後は「こんにちは、Android！」が表示されています。
うまくいかないとき

変える場所を忘れた場合は、手順08を見ます。画面が変わらない場合は、手順09の「うまくいかないとき」を確かめます。
