> 教員向けの制作・検証記録。HTML3ページとPanda 2テンプレートからの変更前後を作成済み。指定環境での通し確認前のため、学生配布はまだ行わない。
> [アプリ仕様](../README.md)・[教材作成方針](../../../docs/teaching-materials-guide.md)に従う。

## 学生に伝える目標

「画面に『こんにちは、Android！』と表示するアプリを作ります。文字を変えて、もう一度動かせるようになりましょう。」

配布時は最初に、教員が実装・検証したアプリの完成画面を見せる。初版では実行画像と誤認しないよう「説明図」と明記した図を掲載している。Javaの文法やAndroidの仕組みをまとめて説明することから始めない。

## 手順09の文章例

以下は文章の粒度の見本。画面上の操作名やボタン位置は、指定Android Studioで確認してから画像とともに記載する。

**この手順でやること**

画面に出る言葉を、日本語に変えます。

**操作する場所**

strings.xmlを使います。表示する言葉が書いてあるファイルです。開き方を忘れた場合は、教材内の「05 使うファイルを開いてみよう」へ戻ります。

**やってみよう**

1. strings.xmlを開きます。
2. `Hello, Android!`を探します。
3. この言葉だけを`こんにちは、Android！`に書き換えます。前後の`<string ...>`と`</string>`は残します。
4. アプリをもう一度実行します。
5. 練習用のスマートフォンの画面を見ます。

変更前：

```xml
<string name="greeting_message">Hello, Android!</string>
```

変更後：

```xml
<string name="greeting_message">こんにちは、Android！</string>
```

これはstrings.xmlの中の1行です。ファイル全体をこの1行に置き換えないでください。実際の教材では、この行が入る`<resources>`内の位置も示します。

**こうなればOK**

画面に「こんにちは、Android！」と表示されます。変更前後の実行画像を並べます。

**うまくいかないとき**

| 見えていること | 最初に確かめること |
| --- | --- |
| まだ英語が出ている | 変更後にもう一度実行したか、実行が完了したかを確認する。 |
| 文字の下に赤い線が出た | 変更前後の例を見て、前後の記号を消していないか確認する。直せない場合は、開いているファイルと赤い線を教員に見せる。 |
| 同じ名前のファイルが複数ある | 手順05の場所と比べる。見分けられない場合はファイル一覧を教員に見せる。 |

実教材では「実行」の操作方法にも案内を付ける。Android Studioの自動保存を前提とし、編集後の手動保存は手順に含めない。スクリーンショットの位置だけで説明せず、確認済みの画面ラベルを併記する。

## 教員側の準備

1. [Stitch参照情報](../design/stitch.md)の対象画面をStitch MCPで取得し、Java・XMLへ反映する。既知の色・寸法・タップ演出の差分を授業仕様に合わせる。
2. Panda 2 | 2025.3.2で新規作成から完成まで通し、テンプレート、SDKなどの固定値と、実際の画面上の操作名を確定する。
3. 完成画面、プロジェクト作成、ファイルの場所、英語表示、日本語表示、実行結果の画像を取得する。Stitchの横長PNGを縦向き実機の完成見本として流用しない。
4. Panda 2のEmpty Views Activity生成直後を開始状態とし、各コマ終了状態・完成状態への差分をそろえる。[テンプレート基準](template-baseline.md)に従い、HTMLの変更前後が順番どおりに適用できることを確認する。
5. HTML3ファイルと画像を作成し、学生の操作手順だけで完成・提出まで進めるか確認する。
