できたか確かめよう

できたことを1つずつ確かめます。

操作する場所　Android Studioと、練習用のスマートフォン

やってみよう

  1. 手順10の文字変更を教員に見せます。
  2. 必須のあいさつへ戻した画面を確かめます。
  3. スマートフォンの「最近使ったアプリ」の一覧を開きます。3つのボタンがある場合は四角のボタン、ジェスチャー操作の場合は下から中央へなぞって止めます。
  4. 自分のアプリの画面を上へなぞり、一覧から消します。
  5. ホームへ戻ります。
  6. アプリ一覧から「はじめてのアプリ」のアイコンを押します。
  7. 同じあいさつが出るか確かめます。
  8. Android Studioで File → Close Project を選びます。
  9. 最初の画面の Open を選びます。
  10. 手順03でメモした A01FirstApp フォルダーを選びます。
  11. 準備が終わるまで待ちます。
  12. Run → Run 'app' を選びます。
  13. 同じ完成画面が出るか確かめます。

完成チェック

できた項目にチェックを付けます。このページのチェックは保存されません。記録を残す場合は、チェック後に印刷します。

ファイルを開いて、教員に伝えよう

短い言葉や、指差しで答えてもよいです。

開くファイル 伝えること
MainActivity.java 画面を表示する指示はどこですか。
activity_main.xml 文字を置く部品はどれですか。
strings.xml 表示するあいさつはどこですか。
こうなればOKC01〜C06を、自分の操作と画面で確かめられました。

アプリの閉じ方がわからない場合は、スマートフォンの画面を教員に見せてください。プロジェクトが開けない場合は、app より1つ上の A01FirstApp フォルダーを選んだか確認します。

提出して、振り返ろう

アプリのファイルと、完成画面の画像を提出します。できたことを振り返ります。

操作する場所　パソコンのファイル一覧と、教員が案内する提出先

提出先・締切・ファイル名は、授業で教員が案内します。案内を確認してから提出します。

① 完成画面の画像を保存する

  1. アプリを実行し、「こんにちは、Android！」を表示します。
  2. 練習用のスマートフォンの周りにある、カメラの形の Take Screenshot を押します。
  3. 保存先を選べる場合は、自分が見つけられる場所を選びます。
  4. 保存された画像を開きます。
  5. 必須のあいさつと、画面全体が写っているか確かめます。

カメラのボタンが見つからない場合は、教員に画面を見せてください。パソコンの画面保存を使う場合も、アプリの上下が欠けないようにします。

② 提出用のコピーを作る

  1. Android Studioで File → Save All を選びます。
  2. Windowsのエクスプローラー、またはmacOSのFinderで、手順03の保存場所を開きます。
  3. A01FirstApp フォルダーをコピーします。
  4. 提出用の別の場所へ貼り付けます。
  5. コピーしたフォルダーを開きます。
  6. 下の表の「入れないもの」を、提出用コピーからだけ取り除きます。
入れるもの 入れないもの
app/src/（Java・XML・画像・Manifest） app/build/ と build/（自動で作られるもの）
build.gradle.kts または build.gradle（ルートとappの両方）、settings.gradle.kts または settings.gradle、gradle.properties local.properties（そのパソコンだけのSDKの場所）
gradle/ の中身、gradlew、gradlew.bat（アプリを作る道具の設定） .gradle/、.idea/、.git/、.DS_Store（見える場合）

gradle/ は必要です。先頭に点がある .gradle/ とは別です。 どちらかわからない場合は、消す前に教員へ見せてください。元の作業フォルダーでは削除しません。

③ まとめて提出する

  1. 提出用の A01FirstApp フォルダーを右クリックします。
  2. Windowsは「ZIPファイルに圧縮する」（または「送る → 圧縮（zip形式）フォルダー」）、macOSは「“A01FirstApp”を圧縮」を選びます。
  3. ZIPと完成画面の画像に、教員が案内したファイル名を付けます。
  4. 教員が案内した提出先へ、ZIPと画像1枚を送ります。
  5. 提出先の画面で、2つのファイルがあることを確かめます。

④ 今日の振り返り

次の答えをノートに書くか、教員に伝えます。下の欄にも書けますが、入力内容は保存されません。必要な場合は、入力後に印刷してください。

こうなればOKプロジェクトのZIPと画像1枚を提出できました。今日できたことを1つ伝えられます。
うまくいかないとき

ZIPに何を入れるか迷った場合は、提出用コピーを教員に見せてください。送信に失敗した場合は、提出先の画面を見せてください。失敗した文章を消す前に確認しましょう。
