# Google Classroomでの教材配布

教材は**課題ごとのZIPをClassroomに添付し、学生がMacへダウンロード・展開してindex.htmlを開く**方式とする。HTML、画像、CSS、比較用コード、開始用プロジェクトを同じフォルダー構成で渡す。

教材内の相対リンクは、開いたHTMLの場所を基準に次のファイルを探す。HTMLだけを添付したり、Classroomのプレビューを教材サイトとして使ったりすると、このフォルダー関係を保証できない。`127.0.0.1:8877`は教員の確認用サーバーであり、学生へ共有するURLにはしない。

## 教員の配布手順

1. 教材の確認後、[配布ZIPの一覧](../distributions/README.md)から対象課題・版のZIPを選ぶ。
2. Classroomの対象クラスで「授業 → 作成 → 資料」を開く。
3. 資料名に課題名と版を入れる。例：`A02 自己紹介カード 教材 2026-09-14-r1`。
4. 「追加 → ファイル」または「Google ドライブ」で教材ZIPを添付する。
5. 以下の学生向け案内を説明欄へ貼り付ける。
6. 教材レビュー後に資料を投稿し、学生用アカウントでZIPのダウンロード・展開・直接表示を確認する。
7. 配布先のURLと再取得したZIPを使い、[掲載確認を記録する](materials-maintenance.md)。取得できない場合は確認待ちのまま修正する。

Classroomの資料にはファイルを添付でき、授業ページでトピックごとに整理できる。[Google公式の資料追加手順](https://support.google.com/edu/classroom/answer/9123621?hl=ja)

ダウンロードを制限する設定がある場合は、対象学生が取得できる設定にする。クラス・学校の権限を使った実際のアップロード、ダウンロード、APK提出はまだ確認していない。

### Classroomの説明欄へ貼る案内

> 教材の開き方
>
> 1. 添付の教材ZIPをMacへダウンロードしてください。
> 2. FinderでZIPをダブルクリックしてください。
> 3. 展開された教材フォルダーを開いてください。
> 4. index.htmlを右クリックし、「このアプリケーションで開く」からChromeまたはSafariを選んでください。
> 5. 目次から、授業で使うページを開いてください。
>
> Classroomのプレビューの中ではなく、展開した教材をブラウザーで開きます。HTMLとassetsは一緒に置き、移動するときは教材フォルダーごと移動してください。
>
> 提出するものは、完成したアプリのAPKファイル1つのみです。提出先は教員の課題案内で確認してください。

MacではZIPをダブルクリックすると同じ場所に展開される。[Apple公式のZIP展開手順](https://support.apple.com/ja-jp/guide/mac-help/mchlp2528/mac)

## ZIPに入れるもの

```text
A02-materials-2026-09-14-r1/
  START_HERE.txt       開き方
  index.html           教材の入口
  lesson-*.html        各週の授業
  exercise.html        演習
  checklist.html       完成確認・APKの提出
  assets/
    style.css
    *.png
    checkpoints/      第15回までの比較用コード
    A02ProfileCard-starter.zip
```

学生向けHTMLから参照するファイルだけを収録する。教員用のplan.md、テンプレートの出所記録、Stitch原本、teacher/solution、検証ログは収録しない。A01も同じ方式とする。

A02の「全文を比べる」は、HTMLページ内で各ファイルを展開して読める。必要な場合にだけ「テキストを保存」で同梱の比較用コードを保存する。JavaScriptや外部サービスへコードを取りに行く処理は使わない。

開始用プロジェクトのZIPはAndroid Studioで作業を始めるための配布物。学生が提出するAPKとは別の用途であり、提出物を増やさない。

## 教材を更新するとき

Googleフォームで受け付けたFBを管理IDで追い、検証・新版ZIP・学生向け更新案内をまとめて作る。[更新管理の手順](materials-maintenance.md)と[現在の残件](../distributions/STATUS.md)を参照する。指定された[配布先Classroom](https://classroom.google.com/c/ODY5NTI3MTEwNzgz)は`android1`として登録済み。

更新版には新しい版名を付けてZIPを作り直す。Classroomの資料名と添付ZIPを同じ版へ更新し、変更した手順を説明欄に短く示す。学生は別のフォルダーへ展開して新しいindex.htmlを開く。教材を更新しても、学生自身のAndroidプロジェクトへ上書きしない。

Webページを直接開く配布へ変更する場合は、HTMLとassetsをまとめて配置できるWeb公開先を別途用意する。Google Driveのファイル共有リンクへの置換だけで、現在の相対リンクが維持されるとは扱わない。

## 検証と残件

- 配布スクリプトは入口からすべての参照をたどり、欠落ファイル・アンカー・教材外参照を検査する。
- 完成したZIPを日本語と空白を含む別の保存場所へ展開し、全参照とファイル内容を再検査する。
- 配布ZIPの識別情報と各ファイルのSHA-256は、ZIPと同名のmanifest.jsonへ記録する。manifestは教員側の記録で、Classroomへ添付するのはZIPのみ。
- 2026年9月14日の確認では、A01の83参照とA02の142参照が展開後も成立し、A02の36種類の比較用コード全文がHTMLと一致した。
- 自動操作ブラウザーのURLポリシーがfile://を拒否したため、ZIP展開後のHTMLを直接開くブラウザー実測は未実施。ローカルサーバー経由の表示確認と区別する。
- 学生用アカウントでの「Classroomから取得 → Finderで展開 → ブラウザーで直接開く」、学校の管理設定下での利用、初学者役の通し確認は配布前に確認する。現在のZIPは教員確認用。
